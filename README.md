#  Café Expresso - Atendimento

##  Descrição do Projeto

O sistema "Café Expresso" tem como objetivo modernizar o atendimento de uma cafeteria por meio de um totem de autoatendimento. Nele, o cliente poderá montar seu pedido, realizar o pagamento e acompanhar o status sem necessidade de filas.

##  Objetivos

* Agilizar o processo de pedidos
* Reduzir erros no atendimento
* Melhorar a experiência do cliente

## Funcionalidades

* Cadastro de produtos
* Adição de itens ao pedido
* Cálculo automático do valor total
* Controle de status do pedido (Pendente, Pago, Em preparo, Finalizado)

## Estrutura do Sistema

### Produto

Responsável por representar os itens do cardápio.

### ItemPedido

Relaciona um produto com sua quantidade e calcula o subtotal.

### Pedido

Gerencia os itens do pedido, calcula o total e controla o status.
